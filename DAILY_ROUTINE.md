# Daily Routine — Learning Journey

## Purpose

This file describes my daily learning routine.

The goal is to keep learning consistent and realistic.

I do not need to study for many hours every day. I need to make small stable progress.

Main rule:

Consistency is more important than intensity.

---

## Best learning time

My best learning time is around 12:00.

I usually function better at this time.

I also have reminders at:

- 10:00
- 12:00
- 16:30
- 21:00

The goal of reminders is not to force a long lesson every time.

The goal is to ask:

- Do I have time?
- Do I have energy?
- Can I do at least a small step today?

---

## Before each session

Before I start, I should answer three questions:

1. How much time do I have?
2. How much energy do I have?
3. What should I practice today?

Possible lesson types:

- English only
- Linux only
- Git / Markdown
- mixed English + Linux
- writing practice
- project documentation

---

## 15-minute session

Use this mode when I am tired or have little time.

Good activities:

- practice one grammar rule
- write 3–5 English sentences
- review one mistake
- learn one Linux command
- update one small Markdown note
- make one small Git commit

Example:

Today I will practice Past Simple for 15 minutes.

---

## 30-minute session

Use this mode when I have normal energy.

Good activities:

- short English conversation
- grammar correction
- 5–7 practice sentences
- one small Linux topic
- update notes in Markdown
- make a Git commit

Example:

Today I will practice Past Simple and add notes to my project.

---

## 60-minute session

Use this mode when I have more time and good energy.

Good activities:

- longer English practice
- writing task of 8–10 sentences
- correction and natural version
- Linux or Git practice
- Markdown documentation
- Git commit

Example:

Today I will practice English, learn one Linux topic, and update my Learning Journey project.

---

## When I am tired

If I am tired, I should not overload myself.

Minimum useful lesson:

- read one note
- write one sentence
- review one mistake
- learn one command
- make one small update

Small progress is still progress.

---

## English daily minimum

Minimum English practice:

- 3 sentences about my day
- or 1 short grammar exercise
- or review 1 mistake from English/Mistakes.md

Example:

Today I worked on my Learning Journey project.

---

## Linux daily minimum

Minimum Linux practice:

- use terminal
- repeat one command
- explain one command in English

Example:

Command:

pwd

English explanation:

It shows the current directory.

---

## Writing practice

After English lessons, I should write a short text of 8–10 sentences.

Good topics:

- my day
- work
- Ubuntu
- Linux
- English learning
- my car
- technology
- future career
- DevOps learning

Writing is important because it shows my real grammar problems.

---

## End of session checklist

At the end of a session, I should check:

- What did I learn?
- What did I practice?
- Did I update Markdown notes?
- Do I need to make a Git commit?
- What is the next small step?

Useful command:

git status

If files changed:

git add .
git commit -m "Update learning notes"

---

## Personal reminder

I am building a long-term system.

The goal is not to be perfect today.

The goal is to become better step by step.
