- Preserve existing lesson history and formatting.
- Add new lessons to the appropriate Markdown file.

## Safety

- passwords;
- API keys;
- access tokens;
- private keys;
- cloud credentials;
- secret `.env` values;
- authentication data.

Do not run destructive, privileged, or history-rewriting commands without explicit explanation and approval.

Do not overwrite changes made by another assistant or by Artem.

## Lesson workflow

For a technical lesson:

1. introduce one concept;
2. provide a practical exercise;
3. analyse the real output;
4. explain errors;
5. ask a short review question;
6. update lesson notes after completion;
7. run checks;
8. review Git changes;
9. commit the lesson;
10. confirm a clean working tree.

Do not claim success without verifying the result.
