## Repository rules

- Do not restart the project from zero.
- Do not overwrite uncommitted work.
- Read existing files before editing.
- Preserve previous lesson notes.
- Avoid unrelated refactoring.
- Quote Bash variables unless there is a clear reason not to.

- Confirm the final Git state.
